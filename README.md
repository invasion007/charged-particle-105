## 三条主线

1. **加速**：牛顿第二定律通道 ≡ 动能定理通道，同一个 `v = √(2qU/m)`；非匀强电场只有能量通道走得通。
2. **偏转**：拆成两段 —— 沿 `v₀` 匀速 ＋ 垂直方向匀加速；`y = Ul²/(4U₀d)`、`tanθ = Ul/(2U₀d)` 只含装置量，与粒子的 q、m 无关。
3. **示波管**：`y ∝ U` —— 把电压的变化线性标定成亮斑的位移；扫描电压把时间"摊开"，得到稳定波形。
